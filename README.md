# portfolio-retail-sales-analyst
Portfolio Data Analyst: Analisis data ritel dengan Python, SQL, dan Excel untuk menghasilkan insight bisnis.

## Project Overview
### Objective
Menganalisis data penjualan ritel untuk:
- Mengidentifikasi produk dengan performa terbaik dan terburuk
- Memahami pola penjualan berdasarkan waktu (harian, mingguan, bulanan)
- Memahami faktor-faktor yang mempengaruhi keputusan
- Memberikan rekomendasi strategis untuk meningkatkan revenue
